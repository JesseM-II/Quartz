# QUARTZ

Is a webpage used to create to do lists.

## Running the Page
To run the page, download all the relevant files being: IBM_Plex_Mono_Var-Roman-info.txt, IBM_Plex_Mono_Var-Roman.ttf, index.html, main.js, RaelaGrotesqueThin-ovpea-info.txt, RaelaGrotesqueThin-ovpea.ttf, README.md and style.css. 
README.md is the only file that is not needed to run the page. It is only there to provide more information about the page. Once they are all downloaded run index.html in the browser.

## Usage

### Creating a To Do List

In the top part of the page there is a text input that has the placeholder "to do list name...". This is used for entering the name of the to do list.

Once the name is put, pressing the button below it with a plus icon will create a new to do list.

### Opening the List

An item should appear below the button with a plus icon with the name of the to do list. Clicking on this item should open the list.

A new section of the page should appear with the name of the to do list at the top of it.

### Closing the List

To close the list click on the close list button in the shape of an up arrow at the top right of the section.

### Deleting a List

To delete the list click on the delete list button at the top left of the section. It is a square button with a minus sign inside it. Then click ok on the alert that appears to delete the list. Clicking cancel will remove the alert and the list will not be deleted.

### Creating a Task

Below the to do list name, there is a text input with the placeholder "task name...". Enter the desired task name and then click on the button below the text input with a plus icon. This will create a new task with the previously entered name.

The task should appear below the button with a plus icon and it should have (from the left) the name of the task, a checkbox and a delete button.

### Editing a Task

Click on the task name and change the text as desired. Changes are saved automatically when the task name is updated. Click away to unfocus the task name.

### Completing a task

The tasks are incomplete by default. In each task there is a blank checkbox. Clicking on it should mark the task as complete and change the appearance of the task.

To make the task incomplete again, click on the checkbox to return the task to it's default state.

### Deleting a Task

On the far right side of the task, click on the square button with a minus sign inside it. Then click ok on the alert that appears to delete the item. Clicking cancel will remove the alert and the item will not be deleted.
